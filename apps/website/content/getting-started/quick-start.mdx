This guide will walk you through creating a fully functional REST API with Najm in just 5 minutes.

## Prerequisites

- Bun 1.0+ or Node.js 18+ installed
- Basic TypeScript knowledge

## Step 1: Create a New Project

Create a new directory and initialize your project:

```bash
mkdir my-najm-api
cd my-najm-api
bun init -y
```

## Step 2: Install Dependencies

Install Najm and its dependencies:

```bash
bun add najm-core najm-di najm-router najm-params hono
```

Update your `tsconfig.json` to enable decorators:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

## Step 3: Create Your First Service

Create a file `src/user.service.ts`:

```typescript
import { Service } from 'najm-di';

interface User {
  id: string;
  name: string;
  email: string;
}

@Service()
export class UserService {
  private users: User[] = [
    { id: '1', name: 'John Doe', email: 'john@example.com' },
    { id: '2', name: 'Jane Smith', email: 'jane@example.com' },
  ];

  getAll(): User[] {
    return this.users;
  }

  getById(id: string): User | undefined {
    return this.users.find(user => user.id === id);
  }

  create(data: Omit<User, 'id'>): User {
    const user: User = {
      id: String(this.users.length + 1),
      ...data,
    };
    this.users.push(user);
    return user;
  }
}
```

## Step 4: Create Your First Controller

Create a file `src/user.controller.ts`:

```typescript
import { Controller, Get, Post, Params, Body } from 'najm-router';
import { UserService } from './user.service';

@Controller('/api/users')
export class UserController {
  constructor(private userService: UserService) {}

  @Get('/')
  getAllUsers() {
    return this.userService.getAll();
  }

  @Get('/:id')
  getUserById(@Params('id') id: string) {
    const user = this.userService.getById(id);
    if (!user) {
      throw new Error('User not found');
    }
    return user;
  }

  @Post('/')
  createUser(@Body() data: { name: string; email: string }) {
    return this.userService.create(data);
  }
}
```

## Step 5: Create the Server

Create a file `src/index.ts`:

```typescript
import 'reflect-metadata';
import { Server } from 'najm-core';
import { UserController } from './user.controller';
import { UserService } from './user.service';

const server = new Server()
  .load(UserController, UserService);

await server.listen(3000, () => {
  console.log('🚀 Server running on http://localhost:3000');
});
```

> **Note**: The `router()` and `params()` plugins are auto-registered, so you don't need to explicitly add them.

## Step 6: Add a Start Script

Update your `package.json`:

```json
{
  "scripts": {
    "dev": "bun --watch src/index.ts",
    "start": "bun src/index.ts"
  }
}
```

## Step 7: Run Your API

Start the development server:

```bash
bun run dev
```

Your API is now running at `http://localhost:3000`!

## Test Your API

Try these requests:

**Get all users:**
```bash
curl http://localhost:3000/api/users
```

**Get a specific user:**
```bash
curl http://localhost:3000/api/users/1
```

**Create a new user:**
```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Bob Wilson","email":"bob@example.com"}'
```

## Key Concepts

### Dependency Injection
The `@Service()` decorator registers your class in the DI container. Najm automatically injects dependencies through constructor parameters.

### Controllers
The `@Controller()` decorator defines a route prefix. All methods with route decorators (`@Get`, `@Post`, etc.) become API endpoints.

### Parameter Decorators
Use `@Params()`, `@Body()`, `@Query()`, `@Headers()`, and 40+ other decorators to extract data from requests.

### Auto-registered Plugins
The following plugins are automatically registered:
- `middleware()` - Middleware management
- `params()` - Parameter resolution (40+ decorators)
- `router()` - HTTP routing

For additional features like guards, database, events, etc., you need to explicitly register the plugins.
